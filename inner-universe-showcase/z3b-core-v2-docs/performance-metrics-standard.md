# 台股量化策略五大績效指標標準（客戶版）

這份文件是給未來策略模型與客戶展示頁使用的短版標準。每套策略不論是回測、模擬交易或實盤追蹤，都先用同一組五大指標呈現，讓客戶快速看懂策略本身的結果。

## 五大核心指標

| 順序 | 指標 | English | 客戶看什麼 |
|---:|---|---|---|
| 1 | 年化報酬率 | CAGR / Annualized Return | 長期資金成長效率 |
| 2 | 最大回撤 | MDD / Maximum Drawdown | 過去最慘下跌幅度 |
| 3 | 夏普率 | Sharpe Ratio | 報酬穩定度 |
| 4 | 獲利因子 | Profit Factor | 總獲利能否覆蓋總虧損 |
| 5 | 每筆交易期望值 | Expectancy | 平均每次交易是否具備正期望 |

## 白話解讀

| 指標 | 簡單說法 |
|---|---|
| CAGR | 如果把整段績效換算成每一年，平均成長速度是多少。 |
| MDD | 策略曾經從資金高點跌到低點多少，客戶要知道最難受的區間。 |
| Sharpe Ratio | 報酬是否相對穩定，而不是靠很大的波動撐起來。 |
| Profit Factor | 所有獲利交易加總後，是否明顯大於所有虧損交易。 |
| Expectancy | 平均每出手一次，是正期望還是負期望。 |

## 固定輸出格式

每份策略報告開頭先放這張表，順序不可調整。

| 指標 | English | 數值 | 解讀 |
|---|---|---:|---|
| 年化報酬率 | CAGR / Annualized Return | xx.xx% | 長期資金成長效率 |
| 最大回撤 | MDD / Maximum Drawdown | -xx.xx% | 最慘下跌幅度 |
| 夏普率 | Sharpe Ratio | x.xx | 報酬穩定度 |
| 獲利因子 | Profit Factor | x.xx | 總獲利能否覆蓋總虧損 |
| 每筆交易期望值 | Expectancy | +x.xx% | 平均每次交易期望 |

## 數值格式

| 指標 | 格式 |
|---|---|
| CAGR | 百分比，保留 2 位小數 |
| MDD | 百分比，保留 2 位小數，負數顯示 |
| Sharpe Ratio | 小數，保留 2 位 |
| Profit Factor | 小數，保留 2 位 |
| Expectancy | 百分比或金額，保留 2 位 |

## 報告分類

每份報告必須清楚標示績效類型：

| 類型 | 使用情境 |
|---|---|
| Backtest | 歷史資料回測 |
| Paper Trading / Simulated | 模擬交易 |
| Live Performance | 實盤追蹤 |

## 勝率怎麼放

勝率可以放在「詳細交易統計」，但不要列入五大核心指標。

原因是勝率高不一定代表策略品質好。策略仍需要同時看 Profit Factor 與 Expectancy，確認平均賺賠結構是否健康。

## 客戶版摘要範本

這套策略的年化報酬率為 xx.xx%，代表長期資金成長效率為 xx。最大回撤為 -xx.xx%，代表過去最慘曾經從高點下跌 xx.xx%。夏普率為 x.xx，代表策略報酬穩定度為 xx。獲利因子為 x.xx，代表總獲利約為總虧損的 x.xx 倍。每筆交易期望值為 +x.xx%，代表平均每次交易具備正期望。

整體來看，這套策略屬於「高報酬 / 中等回撤 / 穩定度良好 / 正期望」策略。

## 固定提醒文字

本績效僅呈現策略模型在指定資料期間內的結果，不代表未來結果。實際交易結果可能受到滑價、手續費、交易稅、流動性、成交量、下單延遲與市場波動影響。

本系統為交易規則量化與下單輔助工具，不提供個股投資建議、不保證收益。使用者須自行評估投資風險。
